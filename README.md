# Binary Battle Club Projects — Student Innovation Showcase

> **Where Student Ideas Become Digital Experiences.**

An official digital showcase featuring websites, applications, educational platforms, creative experiments, and technology projects developed by members of **Binary Battle Club** at **Scope Global Skills University (SGSU)**, Bhopal.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS + Custom Design System
- **3D Graphics & Animations**: Three.js (Spatial Spline Ribbon Path + WebGL Shaders)
- **Bundler**: Vite 8

---

## 💻 Local Development

```bash
# 1. Clone repository
git clone https://github.com/faizanzafarali385-star/Binary_Project_Showcase.git

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build for production
npm run build
```
